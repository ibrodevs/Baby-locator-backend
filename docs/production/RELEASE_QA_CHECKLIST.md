## 3. Пользовательские сценарии

| Сценарий | Действия | Критерий pass / негативный случай |
|---|---|---|
| Fresh parent | Install из Play → disclosure → register | Валидный account; слабый пароль/duplicate корректно отклонены, нет test premium login |
| Login/logout | Valid/invalid creds; logout; вход другим user | Нет данных/permissions прошлого account; серверный token revoke по принятой политике |
| Session restore | Cold start с token, затем airplane mode/5xx | Offline не удаляет token; подтверждённый 401 требует login; service lifecycle одинаков |
| Pair child | Parent создаёт профиль/code; child redeem | Правильная семья; код одноразовый; replay/race не выдаёт второй постоянный token |
| Child limits | 0/1/2 children для free/paid/Lite | Единая политика в UI и всех API, нет обхода через register-child ветку |
| Child rename/avatar/delete | Parent changes own child, stranger attempts | Чужой доступ 403/404; storage cleanup после удаления |
| Location foreground | Child двигается → parent map refresh | Реальная точка/время/accuracy/батарея соответствуют device/API |
| Location background | Свернуть/lock 30+ мин, battery saver | Измеренная cadence и stale indicator; no false online/fresh state |
| Permission change | Deny/one-time/revoke location/background | Понятный restricted/offline status; no silent fake coordinates |
| Map release | Play-signed install, zoom/child switch | Maps загружается, нет API key authorization failure; маркеры нужного child |
| History | Несколько маршрутов, >100 points, timezone/day | Ясная pagination/retention, порядок и даты правильные, чужой history закрыт |
| Safe zones | Create/edit/schedule/enter/exit | Alert один на переход; child только читает, stranger не видит/не меняет |
| SOS | Child SOS при visible/background parent | Alert/notification правильной семье, latency измерена, duplicate suppression; permission denied объяснён |
| Notifications | Token refresh, два devices, logout/switch | Доставка всем разрешённым installations, прежний account не получает сообщения |
| Loud signal | Start/stop, DND/volume/offline child | Реальное выполнение/ACK, expiry старых команд; stop доступен владельцу |
| Device stats | Usage permission on/off, day boundary | Часы/приложения/battery корректны, нет статистики чужой семьи |
| App block/limits | Consent/Accessibility/usage, block/unblock/reboot | Ограничения применяются и снимаются, отказ permission объяснён, политика Play соблюдена |
| Chat/tasks/rewards | Text/file/read, stars approval | Корректная family access, files private, size/type limit, no unbounded list |
| Account deletion | Parent и child удаляются отдельно | DB/storage/webhook PII retention, orphan files не остаются; purchase cancellation объяснена отдельно |

## 8. Что фактически прошло в этом аудите

- Flutter analyze — no issues; 8 existing tests passed; pub get success. Doctor: Android licenses issue.
- Django: check passed; 15 existing tests passed на изолированной SQLite. Hardened synthetic profile check --deploy без warnings; local harness с SSL redirect off имеет ожидаемый W008.
- Migration dry-run **failed**: AppIcon.id drift.
- AAB 23: повторный verifier подтвердил package/version/monitoring metadata/bundletool/JAR signature. Published track неизвестен.
- Синтетические reproductions: 7 исходных + 4 дополнительных небезопасных результата; это не исправления.
- Static API resolve: 54 literal paths paid и 50 Lite без неизвестных маршрутов; это не полная проверка методов/JSON/permissions.
- В 18 native .so AAB 23 все 64-bit PT_LOAD имеют alignment ≥16 KB, armv7 WebRTC =4 KB. ZIP alignment сгенерированных APK и runtime на 16 KB устройстве ещё не проверены; 32-bit результат сам по себе не доказывает блокировку 64-bit релиза.
- Pip audit обнаружил advisories; детали и ограничения в SECURITY_AUDIT.md.
- Lite полный checkout: pub get успешен (14 dependency changes), analyze 90 issues (0 errors/2 warnings/88 info), test **0 passed/1 failed**. Flutter auto changes сохранены в `lite-tool-generated.diff` и восстановлены; итоговый checkout чистый. Release AAB Lite не собирался.
- В Lite обнаружены устаревший bundled backend без lite-token endpoint, tracked DB/tokens/media, лишний mic FGS и window-content capability, отличающаяся от Privacy Policy. Эти проверки не пройдены как release gates.
- Check/deploy/test/migrations вложенного Lite backend остановлены до Django из-за отсутствующего dotenv; в основном venv также отсутствуют gunicorn и PostgreSQL driver. Это ограничивает проверку deployment stack, несмотря на успешные основные SQLite tests.
- Остальные checkbox не отмечены: real Play/RC/FCM/TURN/Android E2E не выполнялись.
